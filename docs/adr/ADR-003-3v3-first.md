# ADR-003: 3v3 is the first and primary balancing target

**Status:** Accepted · 2026-09-04

Small courts, no goalkeeper, walled play. 3v3 gives real passing choices (2 options),
defensive roles (presser + last man + cover) and fast matches (5–6 min). 1v1/2v2/4v4/5v5
are supported by the data model (`MatchFormat`) but will not be tuned until 3v3 is fun.
Court dimensions default to 20×32 m with 3 m goals (`DEFAULT_COURT`).
